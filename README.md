# DoctorCRE

DoctorCRE is the human application for the CARR system. It will provide an
independent user interface and deployment lifecycle while CARR remains the
authority for business records, domain behavior, control, and assurance.

This repository is intentionally minimal while the existing DoctorCRE v5 work
is inventoried in `jbookout/carr-system`. Nothing has been copied or restarted.
The first change will define an evidence-backed migration manifest and the
versioned application-to-CARR contract.

The repository is publicly visible. No open-source license has been selected;
public visibility alone does not grant reuse rights.
